# OFCAT 文档目录

AI 增强型 CAT 浏览器工作台 —— 设计文档库。

## 目录结构

```
doc/
├── 01-需求/
│   ├── 原始需求/          # 用户原话、想法、参考资料、竞品调研
│   └── 需求规格说明/       # 整理后的需求规格(功能/非功能/约束)
│
├── 02-基础设计/
│   ├── 架构设计/          # 总体架构、薄插件+本地引擎切分、模块边界、数据流
│   └── 技术选型/          # 技术栈决策、选型对比与理由(ADR)
│
├── 03-详细设计/
│   ├── 模块设计/          # 各模块内部设计(TM、术语、QA、OCR、编排等)
│   ├── 接口设计/          # 扩展↔本地引擎、AI Gateway、对外 API 契约
│   └── 数据库设计/         # SQLite 表结构(terms/translation_memory/projects/history)
│
└── 04-其他/
    └── 评审记录/          # 设计评审、决策变更记录
```

## 约定

- 文档用 Markdown 编写,文件名建议:`YYYYMMDD-主题.md` 或 `编号-主题.md`。
- 架构/流程图可用 Mermaid 内嵌,或在同目录放 `.drawio` / 图片。
- 每个文档顶部标注:版本、作者、日期、状态(草稿/评审中/已定稿)。
