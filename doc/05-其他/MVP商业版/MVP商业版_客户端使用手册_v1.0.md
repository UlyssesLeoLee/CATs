## 0. 阅读指南

本书是 CATs Tauri 桌面客户端（Rust + WebView + Svelte 5）的**用户使用手册**，供翻译员 / 审校员 / 客户管理员在日常工作时使用。客户端界面截图占位用 ASCII art 模拟布局，实际 UI 在 Sprint 2 W4 落地后替换为真实截图（per 可视化交付原则）。

## 1. 客户端概述

### 1.1 技术栈

| 组件 | 选型 | 理由 |
|---|---|---|
| 框架 | Tauri 2.x | 体积小（< 30 MB）、Rust 核心、安全（默认白名单 IPC）、跨平台 |
| UI 库 | Svelte 5 | 编译时优化、响应式极简、bundle 小（per UI-UX 设计书 v1.0） |
| 本地存储 | SQLite | TM 段缓存、术语缓存、离线队列、用户配置 |
| 同步引擎 | 自研 sync.rs | 基于 last-write-wins + 审计日志冲突解决 |
| 鉴权 | JWT + refresh token | per 接口设计书 §1.2 + ADR-008 JWT 密钥轮换与刷新 |

### 1.2 客户端安装

#### Windows / macOS / Linux

1. **下载**：从客户专属门户 `https://cats.<customer>.internal/download` 获取安装包
   - Windows: `cats-client-1.0.0-x64.msi`
   - macOS: `cats-client-1.0.0-universal.dmg`
   - Linux: `cats-client-1.0.0-x86_64.AppImage` 或 `.deb` / `.rpm`
2. **安装**：双击安装包，按向导走（自动签名校验 + SHA-256 校验）
3. **首次启动**：填写服务器地址 `https://api.cats.<customer>.internal` + 输入账号密码
4. **登录**：JWT 签发 + 本地缓存 refresh token

> 离线安装包需联系客户 SRE 团队提供（per 私有化部署要求）。

### 1.3 三种使用模式

| 模式 | 适用 | 网络要求 |
|---|---|---|
| **在线模式** | 日常办公、网络稳定 | 必须联网 |
| **离线模式** | 飞机 / 高铁 / 客户现场 | 断网可用，恢复后自动同步 |
| **审校模式** | 审校员独立工作台 | 可断网（只读 TM / 术语）|

## 3. 离线模式 + 同步说明

### 3.1 离线模式触发

- **自动触发**：检测到网络断开（HTTP 超时 / TCP RST）→ 自动切离线
- **手动触发**：设置 → 同步 → 「强制离线模式」开关
- **状态指示**：右上角徽章从绿色「在线」变橙色「离线」

### 3.2 离线可用功能

| 功能 | 可用 | 备注 |
|---|---|---|
| 查看 TM 命中 | ✅ | 本地 SQLite 缓存（per 配置：默认 50 万段 / 1 GB）|
| 查看术语 | ✅ | 本地缓存（全量项目术语）|
| 编辑译文 | ✅ | 进离线队列 |
| QA 检查 | ✅ | 本地规则（语法 / 一致性 / 占位符） |
| TM 回存 | ⚠ | 仅本地 SQLite，重连后异步回传 PG |
| 创建新项目 | ❌ | 需联网 |
| 邀请成员 | ❌ | 需联网 |
| 上传新文件 | ❌ | 需联网（MinIO 预签名 URL）|

### 3.3 重连同步

1. 网络恢复 → 客户端自动检测（每 30s 探测一次）
2. **上传离线编辑**：按 FIFO 顺序回传 POST `/v1/tasks/{id}/segments`
3. **下载服务端更新**：增量同步 GET `/v1/sync/diff?since=<last_sync_at>`
4. **冲突解决**：默认 last-write-wins（per segment 时间戳比较），冲突进审计日志供管理员裁决
5. **进度条**：状态栏显示同步进度，同步完成后徽章恢复绿色「在线」

### 3.4 冲突场景示例

| 场景 | 客户端 A（离线）| 客户端 B（在线）| 解决 |
|---|---|---|---|
| 同时编辑 #0034 | Alice 改为 "Hi!" | Bob 改为 "Hello!" | 时间戳比：A 14:23, B 14:25 → B 胜 → A 提示"你的修改已被覆盖，原文已存审计" |
| TM 回存竞争 | Alice 回存 #0035 → TM | Bob 同时手动加同段 → TM | 段文本相同 → 不重复入库；段文本不同 → 两条记录，按 TM ID 区分 |
| 术语删除 | 客户端离线时术语 "World" 被 Admin 删除 | 客户端本地缓存仍含该术语 | 下次同步时本地缓存自动失效 + 弹窗通知 "术语 World 已被删除" |

## 4. JWT 登录 + Refresh 操作步骤

### 4.1 首次登录

```
┌──────────────────────────────────┐
│  CATs 登录                       │
├──────────────────────────────────┤
│  服务器: https://api.cats... 内部 │
│  用户名: alice@lingo-game.com    │
│  密码: ********                  │
│                                  │
│  [登录]   [忘记密码]  [SSO 登录] │
└──────────────────────────────────┘
```

1. 打开客户端 → 默认显示登录页
2. 输入服务器地址（首次需要，记住后下次自动填充）
3. 输入用户名 + 密码
4. 点击「登录」
5. 客户端 → auth-service POST `/v1/auth/login`
6. auth-service 校验密码（argon2）+ 签发 JWT（access 24h + refresh 30d）
7. 客户端保存 JWT 到本地（Windows DPAPI / macOS Keychain / Linux Secret Service 加密存储）
8. 跳转到项目仪表盘

### 4.2 自动 Refresh

- **触发**：JWT 剩余有效期 < 30 分钟时自动 refresh
- **流程**：客户端 → auth-service POST `/v1/auth/refresh`（带 refresh token）
- **返回**：新 access token（24h）+ 新 refresh token（30d，旧 refresh token 失效）
- **失败**：refresh token 过期 → 强制重新登录（清空本地所有缓存）

### 4.3 手动操作（高级）

**查看当前 JWT**：

```
设置 → 服务器 → JWT 有效期（倒计时显示）
```

**手动刷新**：

```
设置 → 账号 → 「立即刷新 JWT」按钮
```

**主动登出**：

```
设置 → 账号 → 「登出」按钮（清空本地 JWT + 缓存 + 离线队列）
```

**查看登录历史**：

```
设置 → 账号 → 「登录历史」（最近 10 次登录 IP / 时间 / 设备）
```

### 4.4 多设备登录

- **支持**：同一账号可在多个设备登录（最多 5 设备，per auth-service 配置）
- **互斥**：超 5 设备时最早登录设备自动登出（per 接口设计书 §3.1 auth-service `MAX_CONCURRENT_DEVICES=5`）
- **设备管理**：`设置 → 账号 → 已登录设备`（可远程登出指定设备）

## 5. 常见问题（FAQ）

### Q1：忘记密码怎么办？

- 登录页 → 「忘记密码」→ 输入邮箱 → 收密码重置邮件（需服务端开启 SMTP）
- 企业 SSO 用户请联系组织管理员重置

### Q2：客户端启动慢？

- 检查 SQLite 缓存大小（设置 → 同步 → TM 缓存）
- 默认 50 万段 / 1 GB；超此建议清理或调小
- Windows Defender 实时防护可能拖慢 SQLite，建议把客户端安装目录加入白名单

### Q3：翻译速度变慢？

- 检查 TM 命中率（仪表盘 → 项目详情）
- 命中率 < 50% 时考虑补充术语库或导入历史 TM（.tmx / .xliff）

### Q4：怎么导出译稿？

- 工作台 → 顶部菜单 → 「导出」→ 选择格式（.docx / .xlsx / .srt / .json / 原始格式）
- 导出走 MinIO 预签名 URL，下载限速 100 MB/s

### Q5：怎么切换语言对？

- 工作台 → 顶部「语言对」下拉框 → 选择目标语言
- 仅显示当前项目支持的语言对（per project-service 配置）

### Q6：怎么联系翻译经理？

- 设置 → 帮助 → 「联系支持」→ 显示组织管理员邮箱 + Slack 频道链接
