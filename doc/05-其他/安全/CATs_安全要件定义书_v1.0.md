## 4. 认证（Authentication）

### 4.1 身份认证

| 场景 | 方案 | 备注 |
|------|------|------|
| 用户登录 | OIDC + OAuth 2.0 | 支持企业 SSO（OIDC IdP） |
| 服务间 | mTLS + JWT | Service Mesh 简化版 |
| 数据库 | SCRAM-SHA-256 + 证书 | PG 14+ 原生 |
| 管理员 | 独立 MFA | TOTP / FIDO2 |
| API | API Key + JWT | 双因素 |

### 4.2 密码策略

- 长度 ≥ 12 字符
- 复杂度：大写+小写+数字+特殊
- 90 天强制更换
- 5 次失败锁定 30 分钟
- 存储：bcrypt cost=12

### 4.3 多因素认证（MFA）

| 角色 | MFA 强制 | 方式 |
|------|----------|------|
| 管理员 | 强制 | TOTP / FIDO2 |
| 项目经理 | 强制 | TOTP |
| 译者/审校 | 推荐 | 邮箱/短信 |
| 服务账号 | 强制 | mTLS + 短期证书 |

## 5. 授权（Authorization）

### 5.1 RBAC 模型

| 角色 | 资源 | 操作 |
|------|------|------|
| 译者 | 项目/文档/术语/TM | R/查 |
| 审校 | + 审校/退回 | R/W（限定） |
| 项目经理 | + 项目配置/报告 | R/W/Admin |
| 术语专家 | 术语 | R/W/Admin |
| QA 工程师 | QA 规则/全量 QA | R/W/Admin |
| 管理员 | 全部 + 用户/角色 | R/W/Admin |

详细见 `CATs_权限矩阵_v1.0.md`（P1 后续整合）。

### 5.2 ABAC（属性）

- 时间窗口：业务时间 vs 维护时间
- IP 白名单：管理员限定
- 设备指纹：异常登录告警
- 数据标签：敏感项目额外审批

### 5.3 权限缓存

- 短期 JWT（≤ 15 分钟）
- 撤销列表（Redis 黑名单）
- 强制刷新：角色变更后

## 6. 数据保护

### 6.1 传输加密

| 通道 | 协议 | 算法 |
|------|------|------|
| 浏览器↔BFF | TLS 1.3 | AES-256-GCM |
| BFF↔MS | mTLS（Istio Linkerd 简化） | TLS 1.3 |
| MS↔PG | TLS | AES-256 |
| MS↔Kafka | SASL_SSL | TLS 1.3 |
| MS↔MinIO | HTTPS | TLS 1.3 |
| MS↔LLM | TLS | TLS 1.3 |

### 6.2 存储加密

| 数据 | 加密 | 算法 |
|------|------|------|
| PG 数据 | at-rest | AES-256-XTS |
| MinIO 对象 | at-rest | SSE-KMS |
| 备份 | at-rest | AES-256 |
| 敏感字段（密码、token） | 应用层 | bcrypt / KMS |
| 翻译内容 | at-rest | AES-256（数据库级） |

### 6.3 密钥管理

- HashiCorp Vault 或云 KMS
- 密钥轮转：90 天
- 密钥审计：所有访问记录
- 密钥备份：异地 2 份

### 6.4 数据脱敏

| 场景 | 脱敏规则 |
|------|----------|
| 日志 | 邮箱/手机/身份证 脱敏 |
| 监控 | 不显示原文 |
| 备份 | 包含敏感数据需二次加密 |
| 测试环境 | 全量脱敏 + 不可逆 |

### 6.5 数据留存与删除

| 数据 | 留存期 | 删除策略 |
|------|--------|----------|
| 翻译内容 | 项目周期 + 7 年 | 用户申请删除 |
| TM | 永久（除非主动） | 用户申请删除 |
| 审计日志 | 7 年（等保要求） | 法定保留 |
| 备份 | 30 天 / 1 年 / 7 年 | 自动循环 |
| 会话 | 30 天 | 自动失效 |

### 7.1 审计范围

| 类型 | 记录项 |
|------|--------|
| 认证 | 登录/登出/失败/MFA |
| 授权 | 角色变更/权限授予 |


### 7.3 日志安全

- 不可篡改（WORM）
- 时间戳签名
- 异地备份
- 7 年留存

## 8. 网络安全

### 8.1 边界

- 外部：WAF + DDoS 防护
- 内部：零信任（mTLS）
- 内部 API：不暴露公网
- 办公网：VPN + 二次认证

### 8.2 防火墙规则

| 源 | 目的 | 端口 | 协议 |
|----|------|------|------|
| 浏览器 | BFF | 443 | HTTPS |
| 办公网 | VPN | 1194 | UDP |
| SRE | K3s API | 6443 | HTTPS |
| CI Runner | K3s API | 6443 | HTTPS |
| 监控 | Prometheus | 9090 | TCP（仅内网） |
| 内部 | Postgres | 5432 | TCP（仅内网） |

### 8.3 DDoS / WAF

- Cloudflare / 阿里云 WAF
- 速率限制：100 req/s/IP
- CC 防护：JS Challenge
- 黑名单：自动学习 + 手动
