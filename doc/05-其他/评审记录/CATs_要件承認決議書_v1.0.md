## 6. 基线变更管理

### 6.1 CAB（Change Advisory Board）

- **组成**：PM（召集人）+ 架构师 + BA + QA + SRE + DBA + 客户代表
- **频度**：月度例会 + 紧急会议（如需）
- **决策**：6/7 多数通过；客户方 1 票否决权（仅限业务/合同事项）

### 6.2 变更流程

```
变更请求（CR）→ 影响分析（IA）→ CAB 评审 → 批准/拒绝/暂缓
                                            ↓
                                   基线更新（Baseline +1）
```

详见 `CATs_工作流文档_v1.0.md` §2.13 + §2.15。
