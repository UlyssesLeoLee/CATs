## 3. 文档命名与位置约定

### 3.1 命名规范

```
CATs_<文档类型>_<主题>_<版本>.md|xlsx
```

文档类型示例：

| 类型 | 含义 | 示例 |
|------|------|------|
| 立项材料 | 超上流立项阶段 | システム化計画書 / Project Charter |
| 需求规格说明 | 10-21 阶段 | 需求定义书 / 安全要件 / 迁移要件 |
| 架构设计 | 22-41 阶段 | 架构设计书 / 报表设计 / UI 设计 |
| 详细设计 | 42-52 阶段 | 接口 / 数据库 / SQL / 类图 |
| 测试设计 | 59-95 阶段 | UAT 计划 / 系统测试报告 |
| 评审记录 | 各 RD/BD/DD 评审 | 决议书 / 评审纪要 |
| 管理 | 131-144 阶段 | 项目管理计划 / WBS / Baseline |
| 运维 | 109-117 阶段 | 运维手册 / 值班表 |

### 3.2 目录约定

| 层级 | 路径 |
|------|------|
| 需求 | `D:\CATs\doc\01-需求\` |
| 基础设计 | `D:\CATs\doc\02-基础设计\` |
| 详细设计 | `D:\CATs\doc\03-详细设计\` |
| 测试 | `D:\CATs\doc\04-测试\` |
| 其他（PMO/评审/管理） | `D:\CATs\doc\05-其他\` |

### 3.3 模板要素

每份文档至少包含：

1. 文档管理信息（编号、版本、审批栏、修订履历）
2. 目录
3. 目的 / 范围 / 读者 / 术语
4. 主体章节（与フェーズ任务对应）
5. 与既有文档的关联引用
6. 待办与 Open Items
