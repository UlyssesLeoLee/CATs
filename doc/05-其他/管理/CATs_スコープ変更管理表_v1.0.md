## 1. 使用说明

由 PM 维护，任何范围变更（含新增/删除/修改功能、性能、约束、合规项）必须先填写本表，提交 CAB 评审。CAB 决议分：批准 / 拒绝 / 暂缓 / 转 v2.0。批准后触发 Baseline +1 并更新 `CATs_项目管理計画書` 与 WBS。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
