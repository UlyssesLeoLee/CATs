## 1. 使用说明

由 PMO 维护，团队成员每周五 17:00 前填报本周工时。PM 每周一汇总并校验偏差（>20% 触发偏差说明）。工时数据是预算核算、SLA 复盘、人员调配的依据，禁止事后补填。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
