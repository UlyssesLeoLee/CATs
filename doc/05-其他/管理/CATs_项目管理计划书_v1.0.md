## 8. 质量管理

### 8.1 质量目标

| 维度 | 目标 |
|------|------|
| 代码质量 | clippy 0 警告；SAST 0 高危 |
| 测试覆盖 | UT ≥ 80%；IT 关键路径 100% |
| 缺陷密度 | < 0.5/KLOC（生产代码） |
| 性能 | 全部 NFR 达标 |
| 安全 | 0 高危漏洞 |
| 文档 | 全部交付物评审通过 |

### 8.2 质量门禁（Gate）

| Gate | 通过条件 |
|------|----------|
| M0 → M1 | 12 项 P0 Closed + Charter 批准 |
| M1-S0 → S1 | 開發環境 + CI 通过 + SAST 集成 |
| M1-S3 → S4 | 15 服务 API 全部集成测试通过 |
| M2-S6 → ST | UT ≥ 80% + 0 致命缺陷 |
| ST → UAT | 性能/安全/灾备全部通过 |
| UAT → 移行 | 客户签字 |
| 移行 → リリース | Canary 100% 冒烟通过 |

### 8.3 QA 工具

- 静态分析：clippy / eslint / ruff
- 测试：cargo test / pytest / Playwright
- 性能：k6 / wrk
- 安全：trivy / OWASP ZAP
- 监控：Prometheus + Grafana + Sentry
