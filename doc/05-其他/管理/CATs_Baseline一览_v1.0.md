## 1. 目的

记录 CATs 项目**所有已批准为基线（Baseline）的文档与版本**，作为：

- 范围与变更的权威依据
- CAB 决议的索引
- 交付物移交清单
- 跨团队契约的版本基准（QA-101）

未经 CAB 流程，**任何对 B0 的偏离需经本表更新（+1）**。

## 2. Baseline 编号规则

```
B<主版本>.<次版本>
```

| 编号 | 含义 | 触发条件 |
|------|------|----------|
| **B0.0** | 当前基线（评审前草稿） | 评审会批准 |
| B0.1, B0.2... | 增量变更（文档级别） | CAB 批准（文档级） |
| B1.0 | 重大基线（含需求/架构重大变更） | CAB 批准（重大级） |
| B2.0, ... | 主版本变更 | Sponsor 批准 |
