## 1. 使用说明

M3 Hypercare 期间，由 PM 协调架构师 / SRE / DBA / QA 对客户运维团队与内部二线支持进行知识移交。架构/SRE 知识必填（🔴），其他维度按客户接收范围填写。每条知识项须有转移方式与验收签字，KT 全部完成才能签发完了判定书。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
