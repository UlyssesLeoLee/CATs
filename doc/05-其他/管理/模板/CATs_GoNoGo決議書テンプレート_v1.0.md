## 1. 使用说明

M3 上线前 D-7，由 PM 召集架构师、SRE、QA、合规、Sponsor、客户代表召开 Go/No-Go 决策会。各方按检查项逐项汇报，PM 汇总风险清单，最终由 PM + Sponsor 双签决议。本决议书是上线前的最后 Gate，决议为 No-Go 时需立即重排上线日。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
