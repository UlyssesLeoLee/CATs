## 1. 使用说明

各フェーズ（Sprint / 阶段 Gate / 项目完结）结束后，由 PM 召集团队召开回顾会。围绕 4 象限（What went well / What didn't / So What / Now What）展开讨论，所有行动项必须有 Owner + 截止日。本文档是组织过程资产的核心输入。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
