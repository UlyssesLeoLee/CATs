## 1. 使用说明

M3 UAT 通过后，由客户在受入判定会上对交付物进行正式判定。PM 负责填写本判定书的元信息与范围，QA 负责人填写判定依据，客户代表签字。本判定书与检收书配套使用：判定为"通过"或"附条件通过"时，触发检收书签发。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
