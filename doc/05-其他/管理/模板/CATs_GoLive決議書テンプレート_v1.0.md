## 1. 使用说明

Go/No-Go 决议为 Go 后，于上线 D-Day 现场由 SRE 发起、PM 主持的最终上线决议。SRE 报告回滚预案与现场就绪状态，PM 确认后由 PM + Sponsor 双签上线。决议为 Hold 时立即启动回滚预案。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
