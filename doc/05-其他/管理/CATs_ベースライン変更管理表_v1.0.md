## 1. 使用说明

由 PMO 维护，登记所有基线（需求 / 设计 / 代码 / 文档 / 部署 / 配置）的变更。任何对已批准基线的修改必须先经 CAB 评审，批准后方可更新基线版本号。每次基线变更后必须同步更新 `CATs_Baseline一览`。

> 字段标记说明：🔴 必填 / 🟡 条件填 / 🟢 自动生成
