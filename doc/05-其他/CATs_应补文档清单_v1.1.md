## 5. v1.1 新增文档模板要点

### 5.1 CATs_ADR 库（任务 22-41 决策记录）

- 路径：`02-基础设计\决策\`
- 格式：每个 ADR 一个 .md
- 编号：ADR-001, ADR-002...
- 模板：背景 / 选项 / 决策 / 影响
- 状态：提议 / 已接受 / 已废弃 / 已取代

### 5.2 评审 / 决议书 模板（94/95/103/107/145）

- 路径：`05-其他\管理\模板\`
- 通用字段：编号 / 决议 / 签字栏 / 备注
- 用途：阶段 Gate 强制产物

### 5.3 收尾模板（147-149）

- 完了報告：项目总结 / 指标 / 复盘
- 振り返り：What / So What / Now What
- KT 記録：知识清单 / 转移方式 / 验收

### 5.4 管理工具表（133-143）

- 风险登记册：风险 / 概率 / 影响 / 缓解 / 责任人
- 课题表：课题 / 解决方案 / 状态 / 关闭日
- 进度表：里程碑 / 计划 / 实际 / 偏差
- 工时表：人员 / 任务 / 工时 / 状态
- 成本表：类别 / 预算 / 实际 / 偏差
- 范围变更表：变更 / 影响 / 决策 / 状态
- 基线变更表：基线 / 变更 / CAB 决议

### 5.5 运维类（109-126）

- 運用マニュアル：日常运维 / 监控 / 备份 / 灾备
- インシデント対応プレイブック：分级 / 响应 / 升级
- キャパシティ管理計画：监控 / 预测 / 扩容
- 保守マニュアル：变更 / 补丁 / 升级 / 紧急
- FAQ：常见问题 / 解决方案
