## 2. 项目愿景（Vision）

打造 **AI 增强型 CAT 浏览器工作台**，让译者：

- 在浏览器中**不切换工作流**完成 CAT 全部作业（翻译/审校/TM/术语/项目）
- 充分利用**本地 LLM + TM + 术语库 + RBAC** 提升效率
- 在 **15 微服务**协同下实现**热插拔部署 + 自动扩容 + 多租户**
- 在 **等保/合规**框架下安全运营

## 4. 范围（Scope）

### 4.1 包含（In-Scope）

| 类别 | 项 |
|------|-----|
| 核心功能 | 翻译记忆(TM)、术语库、机器翻译、本地 LLM、QA 引擎、项目管理、文件 I/O、版本控制 |

## 9. 成功标准（Success Criteria）

### 9.1 M3 验收标准

| 维度 | 标准 |
|------|------|
| **功能** | 11 大功能模块（F1-F11）全部交付，UAT 通过 |
| **性能** | 翻译响应 P95 < 500ms；加载 < 2s |
| **可用性** | 99.9% SLA（年度） |
| **安全** | 等保 2.0 三级（或客户要求级别） |
| **质量** | UT 覆盖率 ≥ 80%；致命缺陷 0 |
| **运维** | 监控/告警/备份全到位；RPO ≤ 1h, RTO ≤ 4h |
| **团队** | 完整交付能力 + KT 完毕 |

### 9.2 终止条件

- 出现关键风险（合规失败 / 资金断裂 / Sponsor 变更）且无缓解路径
- 关键里程碑连续 2 次延期 > 1 个月
- 客户主动终止
