## 0. 阅读指南

**本登记册的目的**:在编码启动前,把所有"我没把握、需要你/团队确认"的东西摆到台面上,按类别列出关心事项、当前假设、建议方案、决策方。

**用法**:
- 评审前,先看 §1 概览(关心事项计数 / 阻塞实施项)
- 评审时,按 §2 各类别逐条讨论
- 决策后,更新"决策方"列与"状态"列
- 编码前,§3 阻塞实施项必须全部 Closed

**配套 Excel**: `CATs_实施前QA登记册_v1.0.xlsx`,12 个工作表(本登记册每个类别一个表 + 概览表 + 阻塞实施表 + 决策矩阵表 + 后续动作表),支持筛选/排序/分类。
