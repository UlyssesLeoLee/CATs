复用指南

  1. 直接复制: 把 vercelserver/ 整个目录拷到任何静态站点项目的根。
  2. 配置 source: 设置环境变量 SOURCE_ROOT=/path/to/your/project (默认 .. = 父目录)。
  3. 跑 build: bash vercelserver/scripts/build.sh — 自动构建源项目并复制到 vercelserver/src/。
  4. 本地预览: cd vercelserver/src && python -m http.server 8080。
  5. 部署: vercel deploy --prod 或推 trigger 分支触发 GitHub Actions。

本套件 不依赖任何 Vercel 特有能力 (无 Edge Functions / 无 Serverless) — 纯静态资源, 可平移到 Cloudflare Pages / Netlify / GitHub Pages / S3+CloudFront 等任何静态托管。
